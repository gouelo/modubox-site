# האתר החדש של מודובוקס

האתר של מודובוקס – מחסנים מודולריים, מחסני גלבוע, שירותים וביתני שמירה.
עיצוב מינימליסטי: קטלוג מלא, סל קניות, הובלה והתקנה לבחירה, הזמנה בוואטסאפ ותשלום (ספק סליקה יחובר בהמשך).

בנוי ב־Next.js + TypeScript + Tailwind, עם Framer Motion לאנימציות. האתר כולו סטטי – מהיר, זול לאחסון ועובד בכל מקום.

## איך משנים דברים באתר

**כמעט כל מה שצריך לשנות נמצא בתיקייה `data/`.** אין צורך לגעת בקוד.

| מה רוצים לשנות | איפה |
|---|---|
| מחירים, מידות, תיאורים, תמונות של מוצר | `data/products.json` |
| תוספות (חלון, דלת, מזגן...) ומחיריהן | `data/addons.json` |
| טלפון, וואטסאפ, מייל, כתובת, דירוג גוגל | `data/site.json` |
| ביקורות לקוחות | `data/reviews.json` |
| סרטונים (יוטיוב) | `data/videos.json` |
| תמונות בגלריה | `data/gallery.json` |
| שאלות נפוצות | `data/faq.json` |
| תקנון | `content/terms.md` |
| אחריות | `content/warranty.md` |

> טיפ: אפשר פשוט לבקש מ־Claude / ChatGPT: "בקובץ data/products.json תעדכן את המחיר של מחסן 3×2 ל־7,900".

### שינוי מחיר של מחסן

ב־`data/products.json` מוצאים את המוצר לפי `slug` (למשל `modubox-3x2`) ומשנים:

```json
"price": 7800,
```

כל המחירים בשקלים, **כולל מע"מ**, בלי פסיקים.

### מחירי הובלה והתקנה

לכל מוצר יש `fulfillment` משלו. כל אחת מהאפשרויות שיש לה מחיר מופיעה ללקוח בסל לבחירה:

```json
"fulfillment": {
  "pickup": 0,                    // איסוף עצמי (0 = חינם)
  "delivery": 300,                // הובלה בלבד
  "installation": null,           // התקנה בלבד
  "deliveryAndInstallation": 1000,// הובלה + התקנה
  "payToInstaller": false,        // true = משלמים למתקין ביום ההתקנה (לא נכלל בתשלום באתר)
  "note": "מצפון לעכו ומדרום לבאר שבע: תוספת 100 ₪."
}
```

`null` = האפשרות לא מוצעת למוצר הזה.

### ערך `null` = TODO

כשמחיר לא ידוע, כתוב `null`. באתר יופיע "מחיר בתיאום" והלקוח יופנה לוואטסאפ. **אף מחיר לא הומצא** – כל `null` הוא משהו שצריך להשלים.

### תוספות

> כרגע התוספות לא מוצגות באתר: הקונפיגורטור התלת־ממדי ייבנה בהמשך על ידי מפתח חיצוני. הנתונים נשמרים כאן בשבילו.

ב־`data/addons.json`. סוגים:

- `toggle` – כן/לא (למשל פאנל חשמל)
- `qty` – כמות, עם `maxQty` (למשל חלונות)
- `choice` – בחירה מרשימה (למשל סוג מזגן)

איזה תוספות מופיעות במוצר – הרשימה `addons` בכל מוצר ב־`products.json`. מחיר שונה לתוספת במוצר מסוים – `addonPriceOverrides` (למשל משטח, שמחירו תלוי בגודל).

### כפתור העיצוב בתלת־ממד

בדף הבית, בקטלוג ובכל עמוד מוצר יש כפתור "רוצים לעצב את המחסן שלכם בתלת־ממד?". ההגדרות ב־`data/site.json`, תחת `design3d`:

- `url` – ריק כרגע, ולכן הכפתור פותח וואטסאפ עם הודעה שמזכירה את המוצר (`whatsappMessage`).
- כשהקונפיגורטור של המפתח יהיה מוכן, שמים כאן את הכתובת שלו, למשל `https://3d.modubox.com/?model={slug}`. את `{slug}` האתר מחליף בקוד המוצר.
- `label` – הטקסט על הכפתור.

### מוצר חדש

מעתיקים מוצר קיים ב־`products.json`, משנים `slug` (באנגלית, בלי רווחים) ואת שאר הפרטים. העמוד שלו נוצר אוטומטית בכתובת `/product/<slug>/`. בכל עמוד מוצר יש כפתור "רוצים לעצב את המחסן שלכם בתלת־ממד?".

## תמונות ולוגו

- **הלוגו:** מחליפים את `public/brand/logo.svg` (ואת `logo-white.svg` לרקע כהה, `favicon.svg` לאייקון בלשונית). כרגע זה לוגו זמני.
- **תמונות מוצרים:** שמים את הקובץ ב־`public/images/photos/` ורושמים את השם ב־`images` של המוצר: `"photos/my-photo.webp"`. התמונה הראשונה היא הראשית.
- **התמונות כרגע** נלקחו מהאתר הישן. כדאי להחליף בצילומים חדשים ואיכותיים.
- גדלים מוקטנים לכל תמונה (לטעינה מהירה) נוצרים אוטומטית בכל `npm run dev` / `npm run build`. אין צורך לעשות כלום.
- עדיף webp או jpg, ברוחב 1600–2400 פיקסלים.

## הרצה במחשב

צריך [Node.js](https://nodejs.org) גרסה 20 ומעלה.

```bash
npm install      # פעם אחת
npm run dev      # פותחים http://localhost:3000
```

בדיקות לפני העלאה:

```bash
npm run check    # טייפסקריפט + lint + בדיקות
npm run build    # בונה את האתר לתיקייה out/
```

## העלאה לאוויר

### תצוגה מקדימה – GitHub Pages

כל דחיפה ל־`main` בונה את האתר ומעלה אותו לענף `gh-pages` (`.github/workflows/pages.yml`), שמוצג בכתובת
`https://gouelo.github.io/modubox-site/`.

### האתר האמיתי – Vercel (מומלץ)

1. נכנסים ל־[vercel.com](https://vercel.com) עם חשבון ה־GitHub.
2. **Add New → Project** ← בוחרים את `modubox-site` ← **Deploy**. אין צורך לשנות הגדרות.
3. מעכשיו כל שינוי שנדחף ל־GitHub עולה לאוויר תוך דקה.

### חיבור הדומיין modubox.com

1. ב־Vercel: **Project → Settings → Domains** ← מוסיפים `modubox.com` ו־`www.modubox.com`.
2. Vercel מציג רשומות DNS (בדרך כלל `A 76.76.21.21` ל־`modubox.com` ו־`CNAME cname.vercel-dns.com` ל־`www`).
3. אצל רשם הדומיין (או ב־Wix, אם הדומיין רשום שם: Domains → Manage DNS) מעדכנים את הרשומות. תוך כמה שעות האתר החדש עולה על הדומיין.

> לפני ההחלפה כדאי לבדוק שכתובות חשובות מהאתר הישן מפנות לחדש (למשל דרך `redirects` ב־Vercel), כדי לא לאבד מיקום בגוגל.
