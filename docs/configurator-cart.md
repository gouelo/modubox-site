# הקונפיגורטור התלת־ממדי ← סל הקניות באתר מודובוקס

מסמך למפתח הקונפיגורטור (Everbox, ‏`web-production-950b8.up.railway.app/il`).
מטרה: לקוח מעצב מחסן בקונפיגורטור, לוחץ "הוספה לסל", והעיצוב שלו נכנס לסל של אתר מודובוקס כפריט עם המידה, הצבע, הפתחים והתוספות.

## מה קיים באתר כבר עכשיו

- האתר (https://gouelo.github.io/modubox-site/, בהמשך modubox.com) פותח את הקונפיגורטור ב־`iframe` בחלונית משלו (לא דרך `embed.js`), עם כפתור **"הוספה לסל"** בסרגל העליון.
- האתר מאזין להודעות `postMessage` **רק** מ־`https://web-production-950b8.up.railway.app` ורק מה־iframe שלו. אם הכתובת תשתנה – נעדכן ב־`data/site.json → design3d.url`.
- כל עוד הקונפיגורטור לא שולח כלום, "הוספה לסל" מבקש מהלקוח לאשר מידה וצבע, ומכניס לסל את המחסן הבסיסי עם הערה שהפתחים והתוספות יתואמו טלפונית. **ברגע שתשלחו את ההודעות שלמטה, הסל יקבל את העיצוב המלא אוטומטית, בלי שינוי נוסף באתר.**

## מה צריך לשלוח (שתי הודעות, שורה אחת כל אחת)

הפורמט הוא ה־query של הקונפיגורטור עצמו – מה שהפונקציה שבונה את ה־URL (`Yi(state)` בבאנדל, זו שמסנכרנת את הכתובת עם `history.replaceState`) כבר מייצרת: `m`, `f`, `p`, `vt`, `fl`, `in` וכו'. אין סכמה חדשה.

### 1. `modubox:design` – בכל שינוי בעיצוב

בכל פעם שהמצב משתנה (באותו מקום שבו אתם מעדכנים את ה־URL), וגם פעם אחת בעלייה:

```js
if (window.parent !== window) {
  window.parent.postMessage(
    { type: "modubox:design", version: 1, design: { query: Yi(state), link: Et(state) } },
    "*" // אפשר לצמצם ל־origin של האתר; האתר בודק את המקור בעצמו
  )
}
```

- `query` (חובה): ה־query string בלי `?`, למשל `m=3x2&f=d&p=.dwwe.d...&vt=5&fl=parquetGrey`.
- `link` (רשות): קישור מלא לעיצוב בקונפיגורטור (אותו origin). נשמר בהזמנה ונשלח לנו בוואטסאפ. בלי `link` האתר בונה `…/il?<query>`.

### 2. `modubox:add-to-cart` – אם תרצו כפתור "הוספה לסל" בתוך הקונפיגורטור

לא חובה (לאתר יש כפתור משלו בסרגל). אם תוסיפו כפתור משלכם, בלחיצה:

```js
window.parent.postMessage({ type: "modubox:add-to-cart", version: 1, design: { query: Yi(state), link: Et(state) } }, "*")
```

האתר מוסיף לסל, סוגר את החלונית ומציג "נוסף לסל".

### הודעה מהאתר אליכם: `modubox:hello`

כשה־iframe נטען, האתר שולח אליו:

```js
{ type: "modubox:hello", version: 1, accepts: ["modubox:design", "modubox:add-to-cart"] }
```

אפשר להשתמש בה כדי להציג כפתור "הוספה לסל" רק כשהקונפיגורטור פתוח בתוך אתר עם סל (ולא, למשל, ב־Wix של Everbox). אם תציגו כפתור כזה – כדאי להסתיר את טופס "בקשת הצעת מחיר" או להשאיר אותו כחלופה.

## איך האתר מתרגם את העיצוב

| בקונפיגורטור (`p` ושדות נוספים) | בסל של מודובוקס |
|---|---|
| `m` (מידה, למשל `3x2`) | המוצר "מחסן מודובוקס 3×2" |
| `f=d` / `f=l` (ברירת מחדל: כהה) | צבע פרופילים שחור / לבן |
| `d` / `D` דלת (הראשונה כלולה) | "דלת נוספת" לכל דלת מעבר לראשונה |
| `b`+`c` דלת כפולה | "דלת כפולה" (נוספות – שורה נוספת באותו מחיר) |
| `w` חלון הזזה | "חלון הזזה כולל רשת" × כמות |
| `G` קיר זכוכית / `s` זכוכית + תריס | "קיר זכוכית ויטרינה" (נוספים – שורה נוספת באותו מחיר) |
| `e` פאנל חשמל | "פאנל חשמל למחסן" |
| `vt` + `D` גריל אוורור | "גריל לאוורור" × כמות |
| `fl=parquetGrey/White/Golden` | "רצפת WPC": אלון עתיק / אלון מולבן / חום טיק (120 ₪ למ"ר) |
| `k` קיפ, `g` דלת זכוכית | שורה "מחיר בתיאום" |
| `if` ריהוט, הפרמטר `b` (מצב התריס), `op` פתיחה | לא נכנסים למחיר (נשמרים בקישור לעיצוב) |

המחירים נלקחים מהאתר (`data/products.json`, `data/addons.json`) והם זהים למחירי ישראל ב־`/api/boot`. אם ישתנו אצלכם – צריך לעדכן גם באתר.

**חשוב:** אם תשנו את פורמט ה־query (אותיות הפאנלים, שמות הפרמטרים) – עדכנו אותנו, או הוסיפו `version: 2` להודעה. הקוד שמפענח נמצא ב־`src/lib/configurator.ts` ובדיקות ב־`tests/configurator.test.ts`.

## בדיקה מהירה

1. פתחו את האתר, דף מוצר (למשל 3×2) → "רוצים לעצב את המחסן שלכם בתלת־ממד?".
2. שנו משהו בקונפיגורטור. אם `modubox:design` נשלחת, הכפתור בסרגל העליון מציג מחיר ("הוספה לסל · 9,980 ₪").
3. "הוספה לסל" → החלונית נסגרת, מופיע "נוסף לסל", ובסל רואים את השורות ואת "עוצב בקונפיגורטור התלת־ממדי".

שאלות: יואל, מודובוקס.
